## 界面与接口

- 复用已确认的统一表单组件；新增使用侧边表单，编辑保留现有详情行内编辑和统一保存。
- 基础信息加入产品线；增加“合同与交付”“项目联系信息”分组；保留计划、ERP、系统分组。
- 新字段进入列设置、筛选和字段目录，不全部加入默认列表。列布局仍按个人偏好保存。
- `GET /api/projects/archives/regions` 提供省市选项，使用档案查看权限；写入仍执行原档案编辑权限、对象范围与产品类别范围校验。
- 新增与编辑复用原档案接口；完整地址组合在服务端再次校验。校验失败不修改档案、不新增同步任务。
- 新字段保存进入原统一操作日志，中文字段名来源于字段注册表/字段目录。
- 金蝶字段映射不变。新建仍登记后台同步；编辑只有项目编码或项目名称实际变化时才登记同步任务。其他字段仅保存 PMS 和操作日志，不清除已有状态/失败原因、不替代已排队任务。失败重试仍由管理员处理；启用/禁用沿用原同步规则。
- 地址逐级展示：默认只有省，选省显示市，选市显示详细地址；新增和编辑分别依据自身表单值判断。换省清空市和详细地址，换市清空详细地址；Esc 恢复本次联动编辑前的值，统一保存包含联动清空。已有完整地址自动展开，地址完整性规则不变。
- 编辑接口返回 `sync_queued`，表示本次保存是否登记了同步任务；前端据此提示“已保存”或“已保存，后台将自动同步金蝶”，不凭前端字段判断推测后台结果。

## 地区数据范围

省市选择器使用版本化、离线打包数据，不在业务录入时联网查询。当前数据快照截至 **2023-06-30**，覆盖大陆 31 个省级地区；暂不包含港澳台及海外地址，不宣称是最新行政区划。直辖市和省直辖县级区域按数据来源处理。来源、许可证、固定提交与校验值见 `backend/app/data/regions/README.md`。更新地区数据需验证已有编码兼容性。

## 升级与回退

- 数据库版本升级为 `2026-09-20-02`，只增加可空列，不回填历史合同日期。
- 两项合同必填规则记录首次升级时间；重复升级、恢复字段规则默认值均不能重置该时间。
- 新建档案记录精确创建时间，避免与升级同一秒创建的记录误享历史豁免。
- 旧字段语义迁移在发现新 `product_line_id` 后停止运行，防止重新将新产品线枚举当作旧产品类别并删除。
- 服务器发布必须先备份并验证、单独执行 `backend/scripts/upgrade_database.py`，再发布匹配代码。仅可重启 PMS；禁止重启服务器或与 OA 共用的 SQL Server 服务。
- 旧程序升级逻辑会删除新产品线枚举，因此**禁止直接切回旧程序并执行初始化**。回退需恢复升级前数据库与匹配程序，或另行制作前向修复，不可仅回退代码。
