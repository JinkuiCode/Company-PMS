# 档案自动同步与同步管理

## 日常使用

- 新建档案点击“保存”后登记后台任务；编辑档案仅在项目编码或项目名称实际变化时登记后台任务（2026-09-21 已部署，程序 `e753619a`）。需要同步时，PMS 保存与后台任务登记同成同败；金蝶处理在后台独立进行，关闭页面不会取消任务。
- 保存成功不代表金蝶同步成功。档案列表的“同步状态”及详情中的“查看日志”可以查询执行情况、失败原因和每次尝试时间。
- 档案维护人员没有单条同步、批量同步或重试入口；同步失败不撤销已保存的 PMS 资料。
- 已写入金蝶或由金蝶期初导入的项目编号不能修改，避免产生第二份金蝶资料。
- 连续修改项目编码或名称并保存，会替代旧的等待/失败任务，只处理最新版本；只改其他字段不登记任务、不自动重试，也不清除已有同步状态和失败日志。真正执行中或待核查时暂不允许修改档案。启用/禁用仍执行原独立同步流程。
- 本次不会自动推送历史档案。启用/禁用功能仍按原有业务规则执行。

## 管理员处理

入口：系统管理 → 同步管理。列表支持项目编号/名称、状态、保存人姓名/工号、任务日期筛选，默认每页 50 条，失败和待核查任务优先展示。

| 状态 | 含义与处理 |
| --- | --- |
| 等待同步 | 已登记持久化任务，等待执行；确认未写入的网络故障也可能短暂回到等待状态 |
| 同步中 | 正在登录金蝶并保存、提交审核 |
| 同步成功 | 金蝶确认完成，或管理员回查确认资料一致且已审核 |
| 同步失败 | 明确失败；排除原因后，管理员可单条或批量重试 |
| 待核查 | 超时、中断或写入结果不确定；禁止直接重试 |
| 已被新版本替代 | 保留历史，不再执行 |

自动重试只适用于明确未发生外部写入的短暂连接故障，最多共三次，等待间隔为 60 秒、120 秒。业务错误不会无限重试。

“待核查”处理：先在金蝶端确认原请求已经处理结束，而不是仅关闭 PMS 页面，再点击“核查”并确认。核查只读取金蝶，不直接写入；重复编码或回查失败仍保持待核查。目标资料一致且已审核则标记成功，否则只有管理员明确确认原请求已终结后才能标记失败，修正原因后再重试。无法确认时应取消，不能盲目重试。

后台执行、过期恢复和人工核查持有同一档案执行锁；旧 PMS 执行进程仍持锁时不能核查或恢复。运行超过 30 分钟且执行锁已释放的任务会被标记待核查。PMS 进程结束不能证明金蝶端已结束处理，因此上述人工确认仍不可省略。接口未提交明确确认时，不一致结果保持待核查。

重试会生成新的持久化任务；旧任务和执行历史保留。重试及核查记录管理员操作日志，保存人仍显示原档案保存人。金蝶原有执行日志与操作日志继续保留；新“档案同步记录”显示本版本开始生成的后台任务。

## 权限

- 管理页面查看：`system:sync:view`；重试/核查：`system:sync:retry`。
- 默认仅系统管理员、业务管理员模板获得新权限；实际授权仍由角色配置决定，不存在管理员代码旁路。
- 查看档案自身任务日志使用 `project:archive:view`，并校验档案数据范围和产品类别范围。
- 旧 `/api/erp/sync` 与 `/api/erp/sync/batch` 直接同步入口停用。将来给维护人员开放手动操作时，应调用同一任务队列，不恢复直接写金蝶的路径。

## 部署与开关

本版本数据库修订号为 `2026-09-20-01`，新增 `erp_sync_task` 表及一次性菜单授权。生产启动不会自动升级数据库。

1. 核实可恢复的数据库备份，停用 PMS 后台执行器，确认无执行中任务。
2. 使用独立升级身份执行 `backend/scripts/upgrade_database.py`，检查修订号、表和菜单；不得重启 SQL Server、OA 或服务器。
3. 部署配套前后端。先保持 `ERP_SYNC_WORKER_ENABLED=false` 验证页面、权限和查询。使用 PMS 运行身份验证 SQL Server 的 `sys.sp_getapplock` / `sys.sp_releaseapplock` 会话锁。
4. 经批准的金蝶联调验收后，将服务器受保护配置中的 `ERP_SYNC_WORKER_ENABLED` 设为 `true`，只重启 PMS。开启前审查所有等待任务，它们会在开启后开始执行。
5. 验证一次保存入队、成功状态、失败原因及管理员重试；核对金蝶业务响应，不以 HTTP 200 代替业务成功。

执行器默认关闭，管理页会提示。任务保存在数据库，服务重启后仍存在。实际执行沿用原金蝶权限与只读配置；开发机不得通过关闭金蝶只读保护来绕过联调批准。

回退前先关闭执行器并处理运行中/待核查任务。已在金蝶写入的资料不能通过恢复 PMS 数据库自动撤回；不得直接切回会绕过队列的旧同步接口。
