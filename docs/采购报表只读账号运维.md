## 验证和失败处理

工具先检查目标数据库和管理员身份、账号不存在、授权列存在。在同一事务中创建账号、授权、模拟新账号检查实际权限并执行无行查询；通过后提交，再使用新账号独立登录复验。权限检查不执行测试增删改。

提交前失败且回滚成功时，移除本次独占创建的本地运行凭据文件。提交已尝试或结果不确定时保留凭据，不丢弃可恢复信息，不盲目再次创建或改密；先根据脱敏结果核查服务器账号。提交后验证失败不自动删账号，需查明错误后处理。

SQL Server 支持事务回滚 CREATE LOGIN，依据：[Microsoft CREATE LOGIN 文档](https://learn.microsoft.com/en-us/sql/t-sql/statements/create-login-transact-sql?view=sql-server-ver17)。列级授权语法依据：[Microsoft GRANT 文档](https://learn.microsoft.com/en-us/sql/t-sql/statements/grant-transact-sql?view=sql-server-ver17)。
