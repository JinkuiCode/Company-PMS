# 即时库存查询报表说明

## 数据来源与权限

数据来源：金蝶正式环境 `10.10.1.248 / AIS20231211221516 / dbo.YD_JIN_INVENTORY`。
本报表只读，不修改库存，不自动刷新或后台轮询。打开页面、调整查询条件和点击刷新时读取当前数据。

必须有“即时库存查询”查看权限，且角色配置对应金蝶组织的产品线。多个角色的组织权限取并集；没有授权组织时返回空数据，不连接金蝶查询。组织筛选显示PMS维护名称，表格组织列保持视图原始名称。

授权通过库存内码关联 `T_STK_INVENTORY.FID`，按 `FSTOCKORGID` 限制，而非按可重命名的组织名称限制。仓库候选与导出执行同一组织限制。报表不以项目负责人或部门限制库存，因为该视图没有项目、负责人字段。

## 字段取值

源视图共11个字段，业务列表展示其中10个；库存内码仅用于内部精确授权关联，不出现在列设置、筛选及导出中。不改变源视图值，不合并行、不去重。

| 页面字段 | 视图字段 | 取值逻辑 |
| --- | --- | --- |
| 库存内码 | FID | `T_STK_INVENTORY.FID`，用于追溯库存记录，不是单据编号 |
| 组织 | Organization | 库存 `FSTOCKORGID` 关联组织名称表的 `FNAME` |
| 仓库 | Stock | 库存 `FSTOCKID` 关联仓库名称表的 `FNAME` |
| 物料编码 | MaterialCode | 物料表 `FNUMBER` |
| 物料名称 | MaterialName | 物料名称表 `FNAME` |
| 规格型号 | FSPECIFICATION | 物料名称表 `FSPECIFICATION` |
| 品牌 | Brand | 物料表 `F_QKTD_Text1` |
| 材质 | Material | 物料表 `F_QKTD_Text` |
| 供应商编码 | SupplierNumber | 物料表 `F_QKTD_Text2`，不是供应商物料号 |
| 基本单位数量 | FBaseQty | 库存基本数量，经原视图转换为 `decimal(8,2)`；展示两位小数，负数保留并标红 |
| 单位 | Unit | 物料基本单位关联单位名称表，中文语言编码2052 |

源视图已排除零库存，只包含视图中列出的五个组织名称。PMS进一步与当前用户有权限的组织取交集；授权不代表视图一定有数据。金蝶新增组织、组织更名或视图范围变化后，需另行检查源视图。

源视图的部分名称关联未限定语言，可能产生重复行；本报表保留其返回结果，不擅自去重。不跨单位汇总数量。原视图数量精度上限也保持不变。

## 查询、列表和导出

- 快速搜索覆盖物料编码、物料名称、规格型号，支持模糊匹配。
- 可选择组织、搜索仓库，也可给10个业务字段添加筛选。文本支持包含、等于；数量支持等于、大于、小于、区间。多个条件同时满足才展示。
- 所有筛选和排序均在数据库分页前执行，默认50条，筛选或每页条数变化回到第1页。支持单列排序；并列值追加字段排序，以稳定分页顺序。
- 列设置支持显示隐藏、首尾冻结、顺序、宽度，点击保存后按当前用户保存在当前浏览器；不跨设备同步。
- 导出需同时具有查看和独立导出权限。按当前筛选导出全部结果，而非当前页；按当前可见字段及排列顺序生成Excel，不包含库存内码，不设500条或1万条业务上限。
- 后台分批读取、按行写入；同一用户一个待完成任务，全系统串行执行。通过“导出任务”查看状态并下载，刷新或重新进入页面可找回最近20次任务。文件保留24小时，失败或过期后重新点击“导出当前筛选”。
- Excel单表达到1,048,576行（含标题）后自动续表。文本不作为公式或链接执行；失败不提供不完整文件。执行期间和下载时重新校验当前角色与组织范围；提交、完成或失败写统一操作日志。
- 新版后台导出在开发机验证完成，服务器发布状态以对应发布记录为准。两张报表通用说明见 `docs/报表导出说明.md`。
- 查询期间显示加载状态，失败显示重试，不保留旧结果冒充新结果。连续改变条件时旧请求不会覆盖新查询。
- 库存是实时变化的数据，总数和明细分两次读取，期间发生库存变动可能导致数量轻微变化，可刷新复核。
