# 报表后台导出说明

## 使用方法

1. 在报表中设置筛选、显示字段及列顺序，点击“导出当前筛选”。导出全部符合条件的数据，不只当前页。
2. 在“导出任务”中查看排队、生成中、完成或失败；生成中可以离开报表或刷新。
3. 完成后点击下载。文件保留24小时；过期或失败后，重新设置需要的筛选并提交新任务。

## 导出内容

- 即时库存：当前可见字段，中文标题，不包含库存内码。库存记录不按物料去重或合并。
- 采购申请主表：当前可见字段，另固定保留申请单编号、申请单行号，作为人工核对关联键。
- 订单明细：申请单编号/行号、项目编号、物料编码/名称、采购订单编号/行号、订单日期、数据状态、作废/关闭状态、采购数量/单位、供应商、是否计入有效数量。
- 入库明细：申请单编号/行号、项目编号、物料编码/名称、采购订单编号/行号、供应商、入库单编号/行号、入库日期、数据/作废状态、实收数量/库存单位、是否计入有效数量。
- 下游明细复用页面来源核对，不能确认归属或组织不符的记录不输出。不同单位不得直接加总；作废、未审核记录与有效数量用状态区分。
- 金蝶数据可能在导出期间被业务人员修改，文件反映读取期间的数据；采购进度筛选按实际导出的关联链汇总后判定，不承诺全库时间点快照。不会修改金蝶数据或隔离级别。

## 权限与容量

- 角色中分别配置 `report:purchase:export`、`report:inventory:export`；另须有对应查看权限。此次不改变已有角色授权。
- 提交、执行和下载均校验权限；执行期间各批次重新检查用户状态、权限和数据范围。组织或项目授权归属变化后，旧任务文件不可下载，需重新导出。
- 不设业务行数上限。每个用户只允许一个未完成任务，全系统同时执行一个任务；库存500行一批、采购200行一批，分批大小不是导出总数限制。
- Excel一张表最多1,048,576行（含标题），自动生成后续同名编号Sheet，不截断。超过Excel单元格字符容量等不能完整写入时，任务失败而非提供残缺文件。
- 文件在PMS项目下 `.runtime/report-exports/`，不开放静态网址，下载接口校验任务所属用户。服务重启后中断任务标记失败，不返回半成品。

## 运维与发布

- 新任务表 `pms_report_export_job`；数据库版本 `2026-09-22-02`。生产需独立升级，不在服务启动时建表。
- 新依赖 `XlsxWriter==3.2.9`；升级前准备数据库备份及程序回退。不重启服务器、SQL Server或OA。
- 原CSV接口返回410，提示刷新页面使用后台Excel导出。新接口：POST/GET `/api/report-exports`、GET `/{id}`、GET `/{id}/download`。
- 提交、完成、失败均记录统一操作日志；查询错误不输出数据库凭据或连接信息。
- 本文记录开发机实现；未发布前，正式环境仍使用旧版本。上线后的性能应按实际筛选范围持续观察，超时会明确失败，不静默减少行数。
