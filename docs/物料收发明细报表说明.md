## 查询范围

- 物料必填，按物料编码、名称、规格型号模糊匹配，空格不能替代必填值。物料为空时查询按钮禁用，回车不触发请求，后端仍拒绝空物料查询。
- 库存组织支持多选且必选，至少选一个；未选择时查询按钮禁用，回车不查询，后端及导出拒绝执行。查询、仓库候选及后台导出始终与当前权限取交集，旧单组织查询方案自动兼容；旧方案未选组织时提示补选，不自动查询。组织变化后清空原仓库选择，避免沿用不匹配条件。
- 仓库只能从候选选择，可以选择全部仓库；开始、截止日期均包含当天。
- 普通用户限角色授权的组织；明确拥有“全部业务数据”权限的用户按系统现有规则查询。角色名称不是绕过授权的依据。
- 只显示数量，不读取或返回价格、金额、成本。已审核、未作废及各来源特定条件按库存报表来源处理，自动生成的重复业务来源按对应规则排除。
- 来源注册表出现自定义插件或未知单据时拒绝查询，不静默忽略该来源。

## 字段取值

| 字段 | 取值逻辑 |
| --- | --- |
| 物料编码 | 对应流水物料内码关联金蝶物料资料的编码；调拨出入两侧分别使用所属侧物料。 |
| 物料名称 | 对应物料资料的中文名称（语言2052）；无中文名称时使用编码。 |
| 日期 | 库存业务单据日期；初始库存使用库存启用日期的前一天；期初行标注查询开始日期。 |
| 单据名称 | 金蝶报表插件对应来源的中文单据名称，如直接调拨单、生产领料单。 |
| 单据编号 | 来源单据表头编号；期初不是业务单据，不显示编号。 |
| 行号 | 来源明细行序号。组装拆卸子件保留独立子件内码，避免与主件混淆。 |
| 仓库名称 | 对应流水侧仓库内码关联中文仓库名称；缺中文名称时用仓库编码。 |
| 库存状态 | 库存状态内码关联金蝶中文名称。 |
| 货主类型 | 金蝶货主类型映射为业务组织、客户、供应商；未知类型保留原标识。 |
| 货主 | 货主类型及内码关联货主名称视图；映射重复时拒绝展示，不能随意取第一项。 |
| 库存单位 | 物料库存属性中的库存单位及其中文名称；不是一律使用基本单位。 |
| 期初 | 查询开始日前的库存结存，按组织、物料、仓库、库存状态、货主等库存维度分别计算。 |
| 收入 | 来源收入方向的基本数量换算为库存单位数量；采购退料等遵循金蝶负收入表示。 |
| 发出 | 来源发出方向的基本数量换算为库存单位数量；生产退料等遵循金蝶负发出表示。 |
| 结存 | 上一笔结存 + 本笔收入 - 本笔发出；分页前计算完整区间，第二页不会重新从零开始。 |

## 期初与数量

1. 存在查询开始日前的库存结账记录时，使用该组织最近一次结账日期的完整结存快照，生效日为结账次日，再补算生效日至查询开始日前的流水。
2. 没有结账记录时，以库存启用日前一天作为初始库存日期，从该基点完整追溯。缺少或重复的启用日期必须报错，不能默认置零。
3. 已有结账记录却缺少该组织快照时拒绝查询。查询某物料未找到快照，不等同于没有组织快照。
4. 基本数量按金蝶库存换算分子、分母及库存单位精度转换，使用十进制定点数；快照同维度先汇总基本数量再换算。
5. 同名物料、不同库存单位或不同库存维度不能混算总数。保管者、仓位、辅助属性、BOM、批号、计划跟踪号、生产及有效期等必要维度也参与结存隔离。
6. 调拨出库、调入、在途、退回和组装拆卸按来源分别处理，不用单一正负号规则替代所有业务。

## 展示与异常

- 默认每页50条业务流水，期初另列，不占业务分页条数。
- 流水按日期、来源排序值、创建时间、单号、行号和稳定行标识排序。
- 详情已打开时随左侧行选择变化；详情关闭时，普通行点击不自动打开。
- 来源读取失败、权限不足、基点缺失或映射异常时，整次查询失败，不返回一部分成功数据冒充完整报表。
- 后台Excel导出包含期初及全部当前条件流水，不按页面或一万条截断；需同时具备菜单、查看、导出权限，运行及下载时复核数据范围。
- 菜单和权限已随独立升级部署；管理员可在报表中心进入，普通角色需要明确配置查看、导出和组织范围，等待业务验收。
