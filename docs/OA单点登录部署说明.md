# OA 单点登录部署说明

## 部署位置

- OA Web 服务器：`10.10.1.247`
- OA 服务器文件路径：`E:\Weaver\ecology\jsp\pms_sso.jsp`
- Web 访问路径：`/jsp/pms_sso.jsp`
- 项目内源文件：`OA对接/pms_sso.jsp`
- PMS 正式访问地址：`http://10.10.1.228`

## 更新步骤

1. 在 OA 服务器上备份现有的 `E:\Weaver\ecology\jsp\pms_sso.jsp`。
2. 使用项目中的 `OA对接/pms_sso.jsp` 替换服务器上的同名文件。
3. 从 OA 菜单进入 PMS，确认页面跳转到 `http://10.10.1.228`，并验证单点登录成功。
4. 如果替换后未立即生效，再检查 OA Web 应用的 JSP 缓存；只有在确认需要时才按 OA 既有运维流程重载对应应用。

## 安全要求

- `pms_sso.jsp` 包含 SSO 签名配置，只能通过公司内部受控方式传输和保存。
- 不得把签名密钥写入本文档、公开聊天、邮件群、截图或故障工单。
- 替换时不得顺带修改 OA 目录下的其他 JSP 文件。
