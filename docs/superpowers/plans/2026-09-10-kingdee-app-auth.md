# PMS 金蝶应用认证实施计划

**批准依据：**同日对话中用户同意四项范围，并追加完整 SOP。

1. 核对官方 SDK 来源、签名入口、只读探测端点与现场授权界面；保留原工作区变更。配置及档案并发基线已通过。
2. 新增 `backend/tests/kingdee_app_auth_contract.py`，先验证新行为缺失导致失败，再实现 `backend/app/services/kingdee.py` 的应用签名模式和查询失败关闭。
3. 在 `backend/app/core/config.py` 添加模式、应用、语系、组织和 `.env.local` 配置；移出硬编码金蝶密码。记录官方 wheel 来源及 hash，更新 `backend/requirements.txt`；不改 OA 或其他凭据。
4. 补充应用配置示例和只读验证脚本。测试禁止真实联网、禁止使用现场凭据。
5. 用户确认账套后，在对应账套建立“PMS系统对接”，仅指定 I0001。按现场界面完成应用信息生成，保护密钥；激活本地应用模式。
6. 运行相关契约测试与真实连接/只读查询，记录日期、账套、模式、结果但不记录密钥。保存测试不在本轮授权范围。
7. 编写 `docs/金蝶第三方应用对接SOP.md`，覆盖建应用、授权、PMS 配置、验证、故障、账号切换、密钥维护、回退与验收记录。尚未完成现场验证时标记待验收，不能宣称成功。
8. 更新本项目 `change.md`，复查差异和秘密保护，交付文件与验证证据。无提交/推送/PR/合并。
