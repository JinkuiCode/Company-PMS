# 全部业务数据授权与主从联动实施计划

> 按已批准方案在当前功能分支执行，采用 executing-plans；不自动合并或部署。

## 已确认基线
- 独立角色授权“全部业务数据”，首次升级授予系统管理员；后续撤权不自动补回。
- 全部范围包含无产品线、无组织映射数据；菜单、编辑、删除、同步及导出权限仍独立校验。
- 新增仍只能选启用产品线，业务校验不绕过。
- 档案和进度详情随行点击切换；草稿提供保存后切换、放弃并切换、取消；快速切换最后一次有效。

## 验收与发布边界
开发机使用隔离数据库验证，不修改服务器数据库；独立升级及服务器部署继续单独批准。回退程序前需恢复相应数据库版本，不伪造版本号。功能权限不扩大，范围授权操作沿用角色操作日志。
