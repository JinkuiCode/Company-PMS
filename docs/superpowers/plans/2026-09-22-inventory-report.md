# 即时库存查询 Implementation Plan

> 使用 executing-plans 在当前任务连续实施；2026-09-22 用户已确认样稿并要求完成。

**Goal:** 按已确认的11列样稿交付金蝶正式库只读库存报表。

**Architecture:** 固定视图、白名单筛选和排序、服务端分页；使用既有独立只读连接。库存FID关联T_STK_INVENTORY.FID，以FSTOCKORGID对照角色产品线组织内码，禁止按中文名称授权。菜单查看/导出分开，导出记录日志。

**Tech Stack:** Vue3、统一列表/表单/列设置、AG Grid、FastAPI、pymssql、SQL Server。

## 边界

- 分支 codex/pms-inventory-report，从当前master创建，保留样稿日志；不自动合并或推送。
- 样稿样式已确认；使用正式统一组件替代样稿原生控件，不新增明细抽屉或汇总看板。
- 11个字段默认全部显示，默认50条；文本包含/等于，数量等于/大于/小于/区间，组合AND；排序和所有筛选在分页前完成。
- FBaseQty保留视图CAST(decimal(8,2))结果，视图排除零库存和部分组织。不跨单位求和。SupplierNumber按视图注释使用“供应商编码”，Material为“材质”。
- 库存无项目及负责人字段，仅按独立库存查看权限和明确组织范围控制；不能借用采购报表的项目档案匹配或空范围全权逻辑。
- 读取权限扩展须单独批准；不使用PMS链接服务器作为正式读取器，不修改视图或金蝶业务数据。
- 新菜单初始化提升数据库版本；本地升级前备份。服务器升级、备份校验和授权分别执行，不重启SQL/OA/服务器。
