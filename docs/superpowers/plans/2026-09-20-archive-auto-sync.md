# 档案保存自动同步与同步管理

## 已批准基线

- 保存档案与登记持久化任务在同一 PMS 事务内完成；后台独立执行金蝶同步。
- 取消档案单条、批量同步及保存并同步按钮，只保留保存。维护人员按数据范围查看状态和日志，不提供重试。
- 同步管理使用标准列表，可按编号/名称、状态、时间、保存人筛选；仅获授权管理员进入并执行单条/批量重试与回查。
- 自动重试仅用于确认未产生外部写入的短暂故障；结果不确定必须先回查，禁止盲目重发。
- 保留最新版本，旧等待任务被替代；同一档案同步执行时沿用既有写入占用保护，不允许并发覆盖。
- 已同步和金蝶期初档案编号锁定；不自动重推历史档案；启停接口保持现状。
- 默认模板仅授权系统管理员/业务管理员同步管理；运行时遵循实时 RBAC，不按角色名称旁路。
- 独立数据库升级，不重启 SQL Server、OA 或服务器；本批先开发机验收。

## 回退边界

金蝶已成功写入的资料不能通过回滚 PMS 事务自动撤回。异常任务保留执行历史、待核查结果及人工处理日志。版本回退前须停用后台执行器并处理运行中任务，不能直接回退至会跳过队列的旧版本。
