# 列布局与角色首页实施基线

用户已确认方案 A、2px 浅灰冻结分隔线、列宽输入与拖动保存，以及角色登录首页。

1. 共享列设置增加布局页：显示列按左/中/右分区，支持冻结、拖动与上下排序、宽度输入。接入既有账号/浏览器 localStorage，固定勾选/操作列，不改业务数据排序。
2. 操作列取消整列填充，保持现有 112px 和按钮标准；冻结区域使用 2px 浅灰分隔。
3. 角色增加首页菜单 ID 与优先级（0-999），有效角色优先级降序、同优先级 ID 升序；仅有效、已授权页面可选，失效则回退首个可访问页面，否则 /403。
4. 统一普通登录、自动登录、OA 各入口的登录后跳转；有效业务深链接优先。不修改凭据、SSO 验签或权限本身。
5. 首页写入角色原有操作日志；字段目录同步；数据库升级幂等兼容 SQLite/MSSQL，提升版本。只升级已确认本机开发数据库，服务器需另批维护窗口及备份，未批准前不部署新角色模型。
6. 验证：先新增列布局行为/首页选择和迁移测试；前端全契约、构建及浏览器布局持久化；后端角色/RBAC/日志/字段目录/数据库升级回归。保留无关工作区修改，不推送或合并 master。

回滚：前端可回到上一版；数据库新增字段兼容旧代码，生产升级及回滚由单独发布计划管理，不修改版本标记绕过检查。
