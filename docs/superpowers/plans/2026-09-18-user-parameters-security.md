# 用户、参数与登录安全实施计划

## 已确认基线

- 参数 A：全宽密集参数表；只维护开发注册参数，不开放任意新增。
- 用户 B：右侧抽屉，统一标签/控件布局，独立滚动、固定头尾。参考 `release/user-settings-design-20260918/index.html`。
- 本批先实现用户与参数；其他系统新增/编辑表单在本批验收后迁移，不改变表格行内编辑。
- 用户账号（工号）、员工姓名、邮箱、手机、部门、多角色、状态。邮箱默认 `@aelsystem.com`，需补全或清空，不推断邮箱。
- 引用 OA 位于头部并突出显示；按工号、姓名模糊搜索，过滤已有 PMS 账号后分页；不显示“创建 PMS 访问账号”。
- 创建不输入密码，读取参数 `user.initial_password`（用户初始密码）；未设置时拒绝创建。编辑底部独立“重置密码”权限和确认，重置为当前初始密码，不连带保存草稿。
- 密码登录首次/重置后强制改密：8–64 字符，不要求字符组合、不定期修改，不允许常见弱密码、账号及初始密码；OA SSO 不要求修改 OA 密码。
- 参数密码只存哈希，不回显、不写日志明文。重置/改密使旧本地凭据失效。OA 自动开户不得使用可登录的占位密码。
- OA 查询固定为 `ecology.dbo.Jinky_Employee`，筛选 `一级部门='总经理'`，只读绑定参数；不可用时保留手工新增。
- 生产数据库服务和服务器不得重启；本批先本机验证，不擅自生产升级、合并 master 或推送。

## 风险与回退

- 新字段/参数表需显式升级数据库，生产启动不执行迁移；旧本地用户下次密码登录要求改密。
- API 创建用户不再接收密码；编辑不能通过 password 字段绕过重置权限。
- 新权限 `system:parameter:view/edit`、`system:user:reset-password` 只首次迁移授权系统管理员，不在启动回补。
- 发布须保留程序和数据库备份；数据库结构与程序共同回退。OA 查询权限不足不扩大数据库权限，报告具体缺失。
