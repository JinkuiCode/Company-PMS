# 列表表头与采购进度快捷筛选样稿

日期：2026-10-08。状态：用户已确认居中表头、快捷栏位置及OA紧凑样稿，已批准开发机正式实施，见 `2026-10-08-oa-compact-workspace-design.md`及对应实施计划。

## 确认范围

1. 所有单据列表字段名统一水平居中，包含普通列、操作列、冻结列及多级分组标题；正文仍按业务语义对齐，不将正文全部改为居中。
2. 恢复采购进度查询页面的快捷状态筛选，沿用当前浅色紧凑风格，优先保证报表可用高度。
3. 已批准调整正式页面；不改权限、数据库或服务器。

样稿入口：`frontend/prototypes/purchase-quick-filter.html`。

## 视觉基线

- 复用 PMS 内置字体、主题令牌、表单控件与 AG Grid，不另建视觉体系。
- 工具栏和查询条件保持现有结构；快捷栏放在查询条件下方、表格上方，按最终紧凑样稿高26px、快捷项24px，文字12px。
- 六个快捷项：全部、未下单、部分下单、待入库、已完成、数据待核对。使用轻量文字与选中下划线，不增加大块状态卡片或未经查询的数量统计。
- 分组标题及字段标题居中。文本正文维持左对齐，数量正文维持右对齐。
- 窄屏允许查询控件换行，快捷栏横向滚动，表格保持内部滚动。

## 交互基线

- 首次进入不自动查询业务数据。点击查询或快捷项才执行查询。
- 点击快捷项提交当前全部有效查询条件并回第一页；点击全部仅移除采购进度条件，不清除产品线、项目、日期或供应商。
- 快捷栏与添加条件使用同一份采购进度条件，不允许相互叠加成隐性冲突；选中快捷项替换现有采购进度条件，其他字段条件保留。
- 添加条件存在一个采购进度等于条件时，快捷栏显示对应选中态；非单一等于条件显示自定义，不将其错误表示为全部。
- 保存方案包含采购进度状态。恢复方案只恢复条件和选中态，仍由用户点击查询生效。
- 翻页、排序、导出均使用成功查询的条件快照；条件改动尚未查询时保留待查询提示，不导出未执行的新条件。
- 数据错误、并发覆盖保护、权限范围沿用既有机制；本批不调整金蝶业务口径或数据权限。

## 确认后实施

- 在共享表格主题落实 AG Grid 与 Element Plus 表头居中，并清理影响本规则的局部对齐覆盖。排序图标、菜单、拖动改宽和冻结边界不得被破坏。
- 将表头规则补充到项目开发准则和 UI 标准，用契约及浏览器测试约束后续新增页面；样稿内的局部预览样式不直接作为正式业务页面特例保留。
- 在采购页恢复快捷栏，兼容既有查询方案的采购进度条件和旧版独立 progress 值；不重复增加冲突条件。
- 复核档案、进度、三个报表及系统管理列表的标题，补充快捷筛选、方案恢复、分页和导出快照一致性回归。
- 运行项目要求的样式、列表、系统UI契约及生产构建；正式功能实施后另行验收。不在本阶段部署、合并主分支或推送GitHub。

## 样稿验证范围

- 六个快捷项及选中状态、模拟结果、回第一页。
- 保存方案、重置、恢复方案、添加条件中的同一采购进度值。
- 1366、1600、1920及390px宽度，无页面横向溢出；普通字段和分组标题居中。
- 不发送业务API请求；导出及列设置在样稿中禁用，明细仅保留视觉占位，正式联动在实施批次验证。
