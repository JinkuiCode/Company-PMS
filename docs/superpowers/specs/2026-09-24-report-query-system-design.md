## 统一布局

1. 方案栏：查询方案选择、保存方案；右侧导出和列设置。方案按报表独立，不混用不同报表字段。
2. 快捷条件栏：有可见字段标签，统一控件高度与间距；常用条件固定，必输条件明确星号。动作区为查询、重置、更多条件。窄屏换行，不压缩文字或覆盖控件。
3. 更多条件：右对齐面板，条件按“字段、运算符、值、删除”整齐排列。添加条件、清空、取消、应用。取消不改变条件；应用不触发查询。
4. 状态栏区分未查询、查询中、条件已修改待查询、已查询、查询失败、无结果。查询成功显示数量及查询时间；条件变更不把旧结果冒充新结果。
5. 列设置复用PmsListColumnPicker：显示、顺序、首列/中间/尾列冻结、列宽与保存。样稿使用现有真实组件，不另做相似组件。

## 字段与运算符

| 类型 | 运算符 | 控件 |
| --- | --- | --- |
| 文本 | 包含、不包含、等于、不等于、开头是、结尾是、为空、不为空 | 文本框 |
| 数量 | 等于、不等于、大于、大于等于、小于、小于等于、区间、为空、不为空 | 数字框，区间用两个数值 |
| 日期 | 等于、早于、晚于、日期范围、为空、不为空 | 日期或日期范围 |
| 枚举/组织/仓库 | 等于、不等于、属于、不属于、为空、不为空 | 单选或多选 |

字段目录声明类型、允许运算符、候选来源、必填、依赖、后端支持情况。只展示后端确实支持的组合；样稿展示上述规范，正式支持矩阵需要在实施计划中逐报表落实。首批高级条件使用“同时满足全部条件”（AND），不引入任意SQL表达式或嵌套逻辑。

切换字段重置运算符和值；切换运算符重置不兼容的值。为空/不为空不显示输入框。空白的非空运算符条件必须提示补全，不能静默忽略。范围必须起点不大于终点。组织与仓库用稳定内码，仓库候选依赖组织；物料收发仓库只能选择。

## 执行状态与查询快照

- draft是编辑中的条件；applied是最近一次成功执行条件的独立快照。
- 进入页面只初始化元数据、权限、列偏好和方案；不自动查询业务数据。候选列表按需加载，与主报表查询分开。
- 修改条件、应用更多条件、切换方案、重置条件均不查询。查询按钮/回车是提交入口；必输或条件校验失败时禁止提交。
- 查询成功后，翻页、改变每页条数和排序基于applied；编辑条件不会夹带到翻页或导出。
- 条件有变更时保留旧结果并明确标记“条件已修改，待查询”。重置清空编辑条件（保留报表固定约束/日期默认），不自动查询，也不误标旧结果。
- 导出使用applied而非draft；无成功查询或无结果时禁用。有未提交修改时提示导出的是上次查询条件。后台导出继续复核权限。
- 点击查询回到第一页并处理旧详情；失败不把新条件标记为已执行。过期响应不得覆盖新结果，查询中重复提交禁止。方案切换或重置使正在执行的旧请求失效。

## 三张报表

- 即时库存：常用物料、库存组织、仓库；高级筛选来自受支持的视图字段。默认不查，不新增用户未批准的物料必填要求。
- 采购进度：常用物料、申请日期、采购进度；更多条件含项目编号、供应商等受支持字段。2026-01-01起始范围是不可扩大约束。组织权限、关联来源校验不变。
- 物料收发：物料、库存组织（多选）必填；日期范围必填；仓库选填且只能选择。保留全部已确认库存计算与权限规则。基于结果数量的过滤不得破坏期初及结存计算，正式阶段须在完整计算后按明确定义过滤，不直接裁剪原始流水。

## 空值与数值

物料收发普通null/缺失值不再显示“-”，显示为空；四个数量字段继续两位小数、显示为零留空。数据仍区分null和0，“为空”不等于“等于0”。错误/未知状态/无法确认的采购数量仍明确告警，不因空值美化隐藏。其他报表的数值精度不在本批自动扩大修改。

## 模块划分（拟定，不在样稿阶段替换生产）

- 复用PMS表单控件、PmsDataList、AG Grid及PmsListColumnPicker。
- 共享报告查询栏、类型化条件编辑器、查询方案管理及draft/applied状态管理；每张报表仅配置字段能力、快捷字段、必填与固定约束、候选加载和接口适配。
- 后端以字段白名单和类型化运算符构造参数化查询。列表/总数/明细/候选/导出共享生效条件与权限，禁止客户端表达式直接拼SQL。
- 现有useListFilters可提取兼容能力，不在报表试点时连带改变档案和进度的即时筛选交互。
- 现有保存方案需要版本化兼容；无效字段提示而非扩大查询范围。角色数据权限不随方案保存，执行时实时取值。

用户已确认 `report-query-v2.html`，批准开发机正式实施。此版覆盖下述早期布局约定：快捷条件不再使用外置同行标签，不再在窄屏隐藏次要条件；控件及按钮统一32px/13px，查询操作紧随条件，自然换行。三个报表统一“添加条件”，列头只显示中文名。实施规范见 `docs/PMS-REPORT-QUERY-STANDARD.md`，本批不包含服务器部署或数据库升级。

### 2026-09-24 已批准的紧凑布局修订

- 以现有工作机报表的密度为参考，取消重复大标题；方案、状态、导出、列设置共用工具栏。
- 快捷字段标签与控件同行排列，减少上下留白；不缩小字号或表格行高。
- 窄屏次要快捷条件可展开收起，物料收发的物料、组织、日期必填条件始终可见；高级条件仍使用浮层。
- 剩余高度交给表格明细。仅调整样稿，正式接入仍待视觉验收。

样稿：三报表同一布局；进入/改条件/方案/重置不查询；必输拦截；类型运算符正确；更多条件取消与应用；null与0筛选不同但普通展示一致；方案/列设置保存；已执行条件分页与导出；空结果、失败、只读、禁用、焦点、窄屏。

正式迁移另需：接口过滤与统计导出一致，授权不能绕过，源数量/精度不变，大数据分页，旧方案兼容，OA嵌入及Windows/macOS验收。样稿验收不等于生产功能完成。
