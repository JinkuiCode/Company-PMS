# 查询条件单字段规范

2026-10-13用户确认上一条方案：所有查询方案取消一项同时匹配多个业务字段的综合条件，先开发机验收，不部署。

采购总/明细取消keyword，分别使用bill_no、material_code、material_name、specification；即时库存取消keyword，使用MaterialCode、MaterialName、FSPECIFICATION；项目档案取消keyword综合搜索，已有项目编号、名称、客户、序列号独立条件继续使用。同步任务message只有一项物理字段，改称执行信息，不拆伪字段。其他列表审查后保持原有单字段查询。

物料收发取消material综合条件，按material_code、material_name、specification独立匹配；至少一项正向物料条件（包含、等于、左包含、右包含）须有值，产品线和日期仍必输。选定的一项正向物料条件限制数据库源读取；其他条件沿用已批准的展示筛选语义，不截断计算所需发生额。期初和发生额使用同一物料字段谓词，运行余额算法不变。新UI不发送综合keyword或合并material含义。旧接口参数保留供历史已提交请求兼容，但material仅匹配指定单字段，默认物料编码。

默认方案采用独立物料编码，其他字段自由添加；所有条件按现有AND组合，不新增OR分组。旧个人方案含已移除综合字段时保留原始存储和名称，提示重新配置并禁止查询；不得静默删条件后宽范围首查。共享工作区已具备失效字段提示/禁查，本批以行为测试复核。

实施细化：源读取和期初均保留选中条件的实际匹配操作（包含、等于、左包含、右包含），禁止把等于放宽为包含。共享requiredGroup元数据表达物料至少一项，红星只标记当前有效代表项；方案可以只显示物料名称或规格，无须强制保留物料编码。全部隐藏或仅否定操作时在实际字段行显示错误并阻止保存/查询。

查询布局、权限、导出授权和数据库版本不变。验证同名值不会误命中其他字段、组合条件、字符转义、旧方案禁查、物料至少一项及期初/发生额同源规则，验证列表、导出同口径；遵循已有紧凑样式，不重新设计基础控件。

用户追加问题提报说明按钮并于本批确认说明范围，复用标准说明容器、操作/字段搜索和新页签。同时批准将所有新增功能页面接入该独立模块写入开发标准；旧页面仍按批准批次迁移。
