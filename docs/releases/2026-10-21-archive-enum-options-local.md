## 行为

1. 每个枚举 code 只采纳最新读取结果，普通读取加入最新在途请求；旧响应和旧失败不覆盖新结果，也不删除新请求的 pending 状态。刷新失败后不复用陈旧可选缓存。
2. 打开新增、恢复草稿和重新打开枚举选择时读取当前选项。读取中不可新选，失败后清除可选候选、保留历史名称与用户输入，提供只读重试。禁用历史值仅保留显示。
3. 后端档案调用层继续执行原枚举校验，拒绝时补充结构化字段定位；统一枚举接口与其他业务协议不变。草稿、正式保存、直接编辑、审批和临时维护失败均保留输入，不自动改选或重试写入。
4. 审批/维护提交被拒绝时显式结束保存等待，避免慢选项读取与确认框关闭动画共同造成列表“保存后切换”永久等待。
5. 项目档案共享页面说明同步更新，复用现有表单、视觉令牌与详情容器。
