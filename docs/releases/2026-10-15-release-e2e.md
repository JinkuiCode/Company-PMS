- 合成服务清单版本v1.0.0、提交aaaa…、标题“隔离联调样本：版本通知”都是明确测试输入；截图显示开发环境及“不代表正式版本发布”。验收凭据也仅为测试夹具，不是正式构建的现场验收凭据。

## 已验证结果

| 目标行为 | 结果 |
| --- | --- |
| 无发布权与幂等 | 普通人发布403；同版本重复发布仅1份记录 |
| 受众完整性 | 4个启用用户各1份站内通知及邮件记录；停用用户没有记录 |
| 邮件与已读分离 | 3个有效合成地址经本机TLS接收，缺邮箱1条失败；全部通知初始未读 |
| 个人操作边界 | 跨用户标已读404；打开通知不已读，点击后仅本人已读；另一用户仍未读 |
| 普通人与管理界面 | 普通人无技术信息/投递管理，管理端真实显示4人的投递及已读状态 |
| 结果未知与重试 | 夹具注入unknown；未确认未收件返回422，页面需原因和确认复选框后才能重试 |
| 原会话即时撤权 | 重试撤权后下一次POST403且保留原因；投递管理和发布撤权后原JWT请求403；3项授权最终均已移除 |
| 内容一致性 | 关于页、通知、预览及本机接收邮件均含同一发布内容及页面说明关联 |
| 窄窗 | 518px下通知已读状态和主要操作可见 |

最终1份发布、4通知；邮件3 accepted/1 failed，接收器共4封（包含1次人工确认后的受控重试）。unknown是人为注入的测试状态，没有模拟真正SMTP连接中断；实际企业邮件服务器及真实收件箱仍未验收。“服务器接受”不代表收件人实际看到邮件。
