# 当前页筛选与参数回显：开发机记录

## 范围

本批仅开发机实施，不部署正式程序，不升级正式数据库，不合并或推送。
表头查询仍查询全部授权结果；列漏斗只过滤已加载的当前页，不重新读取后台候选、不改变总条数、汇总口径或导出范围。
翻页、改每页条数、重新查询、重选方案及接受新数据时清除列过滤和未应用草稿。

分页共用15、20、50、100、200、300、500，默认50；相关引用对话框与后端读取上限同步支持500。
筛选弹窗沿用24px查询尺寸及主页面语义色，不影响32px业务编辑器。

## 初始密码

新增可空认证密文列，原密码哈希保留。仅具有参数查看权限的用户可回显用户初始密码；其他敏感参数仍不回显。
接口禁止缓存，审计不记录密码、哈希或密文，浏览器不持久化该值；撤权和离开页面清除内存值。
旧环境仅有哈希不能恢复密码，需要管理员重新保存。若解密失败或密文与当前哈希不一致，隐藏回显并提示重新保存；创建用户仍使用当前哈希。

认证加密使用AES-GCM，随机nonce和参数身份绑定。优先使用受保护配置中的PARAMETER_ENCRYPTION_KEY，未单独配置时按独立用途从既有SECRET_KEY派生密钥。密钥须至少32字符，禁止写入Git、命令参数、日志或本记录。
密文携带shared/dedicated模式；已有shared密文仍依赖原SECRET_KEY。轮换或遗失相应密钥会使旧值不能回显，但不会破坏哈希使用；管理员须通过本机受控输入重新保存参数。数据库备份与对应密钥应分别受控保管。

开发机先在线备份并校验SQLite，再执行upgrade_database.py的parameter-secret-only限定模式；仅新增sys_parameter.secret_ciphertext，不重放历史初始化或权限授予。
备份：.runtime/backups/pms-dev-before-parameter-secret-20261012-133113.db；完整性及原账号、授权、参数哈希和业务数据保持检查通过。

回退需配套旧程序及parameter-secret-rollback限定模式，保留新增列和原哈希，不删除密文。回退期间旧程序修改密码后，再升级时旧密文无法通过哈希一致性检查，不会显示错误旧密码。
不得只改数据库版本标记或在启动时自动升级。正式发布仍需独立批准、有效PMS备份、受保护配置备份及MSSQL维护窗口；本批未验证真实MSSQL2017 DDL和失败回滚。
