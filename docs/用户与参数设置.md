# 用户与参数设置

## 管理员操作

1. 在“系统管理 / 参数设置”维护“用户初始密码”。没有预置固定密码；未设置时不能创建用户或重置密码。
2. 在“用户管理”点击“新增用户”。账号（工号）创建后不可修改，员工姓名、邮箱、部门和角色按需维护。
3. “引用 OA”按工号或姓名模糊搜索，仅展示尚未在 PMS 开户的员工。选择后回填工号和员工姓名，不自动推断邮箱。
4. 邮箱默认显示 `@aelsystem.com`，保存前补全地址或清空。邮箱暂不发送通知，只作为后续通知地址。
5. 编辑用户时可点击左下角“重置密码”，需要单独的重置权限。确认后立即重置为当前参数中的初始密码，不会顺带保存正在编辑的资料。

## 密码与 OA

- 本地密码首次登录、管理员重置后，先设置个人密码才能进入业务页面。
- 新密码为 8–64 个字符，无强制字符组合、无定期修改；不能使用初始密码、当前密码、常见弱密码或与账号/姓名/公司标识完全相同的值。
- 初始密码不执行上述强度规则，但必须非空且不超过 64 个字符。
- OA 单点登录不要求用户修改 OA 密码。OA 自动开户默认不启用本地密码登录；管理员明确重置后才启用本地密码。
- 重置和改密会使原有 PMS 登录凭据失效；不会修改 OA 密码。
- 初始密码只存不可逆哈希，页面不能查看已保存密码；显示切换仅用于当前新输入的内容。操作日志不记录密码和哈希。
- 本地密码连续失败达到 5 次后，账号或直接客户端 IP 在 15 分钟窗口内暂时受限；OA 身份登录不受该密码失败计数影响。
